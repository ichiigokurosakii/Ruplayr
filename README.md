# Ruplayr

Ruplayr is a native Android streaming-discovery app inspired by CloudStream's browsing experience. It is being built as a standalone app, not a WebView wrapper.

## Planned features
- Native dark UI for browsing movies, TV shows, and anime
- Search and metadata/posters
- Details and episode screens
- Movy source-resolution integration
- Media3 ExoPlayer playback

## Build
Open this repository in Android Studio and let Gradle sync. The project targets Android SDK 35 and uses Kotlin + Jetpack Compose.

The app is an early scaffold. Source resolution and playback will be connected in subsequent implementation steps. Availability of third-party streams depends on the source site and its requirements.
